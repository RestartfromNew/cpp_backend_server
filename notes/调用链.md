# 服务器启动调用链
启动服务器

```TcpServer server{"0.0.0.0", 8080};server.start();```

监听连接

生成fd,并把所有权转交给connection

``UniqueFd clientFd = server.acceptConnection(); 
if (!clientFd.valid()) { continue; }
Connection connection{ std::move(clientFd)};``

注册路由


`` router.addRoute(
            HttpMethod::GET,
            "/user",
            [&userHandler](
                const HttpRequest& request
            ) {
                userHandler.getUser(request);
            }
        );``
